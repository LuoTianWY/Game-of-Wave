# 六边形节点贴图（音色大类）

音轨「加点/减点」处六边形节点的贴图素材，按**音色大类**一一对应。
形状统一为**尖顶朝上下**（pointy-top，与 `HexLayout.Corners()` 的方向一致）。

运行时取用：`Resources.Load<Sprite>("HexNodes/<文件名>")`

## 素材说明

- 每块六边形为**同色系双层边框**：外圈比主体暗约 20% 的描边，内圈比主体亮约 25% 的细高光边。
- 生成提示词见仓库根目录 `即梦六边形色块提示词.md`。
- **已规范化**：尺寸统一为 **443×512**（正六边形比例 宽:高 = √3:2 ≈ 0.866），
  六边形精确占满整图。因此六边形贴图直接用整图 UV，不需要逐图查表。

### 重新生成素材后如何规范化

AI 出的图里六边形大小/位置都不一致（实测宽高比 0.92~0.955，还带接近白的背景噪点），
直接使用会出现白边和大小不一。规范化步骤（Python + Pillow）：

1. 用**亮度阈值 245** 找六边形包围盒（背景是 252~255 的浅白，阈值放宽会把噪点算进来）；
2. 按包围盒裁剪；
3. 缩放到 `443×512`（强制正六边形比例，会横向压缩约 6~10%）；
4. 覆盖保存。

规范化后六边形高度一致、无白边，且与代码里 `HexLayout` 画的几何六边形完全吻合。
