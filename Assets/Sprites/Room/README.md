# 排练室背景图

整张的排练室背景图。每张图的 PPU 都已按自己的像素宽度算好，导入后世界尺寸都是
**21.33 x 12 单位**，正好等于相机视野（正交尺寸 6，位置 (-0.5, -0.5)），
所以换图时不需要调位置和缩放。

| `room_backdrop_empty_v1.png` | 1920x1080 | 90 | 候选项：按策划参考图去掉全部家具和文字后的空房间，四周带一圈浅灰留白。 |

## 怎么换背景

在层级窗口选中 `Room/Backdrop`，把 Inspector 里 SpriteRenderer 的 **Sprite** 字段换成想用的那一张，
位置和缩放都不用动。

**不要用改文件名的方式替换。** Unity 认的是 `.meta` 里的 GUID，不是文件名；改名会让场景里的引用断掉，
Backdrop 会变成没有贴图的空白。要换只能改 Inspector 里的 Sprite 字段。
