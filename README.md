## 1. 游戏概述

### 1.1 一句话定位

玩家经营一支乐队 / 音乐公司，**每个角色的性格被可视化为一段波形**；玩家把角色编排成多轨和声，最终「演奏」出一段**属于自己的音乐**。

### 1.2 项目背景

- 类型：2D 像素风 · 模拟经营 + 音乐创作（轻度策略）
- 引擎：Unity 2021.3.45f2c1，2D 模板，Built-in Render Pipeline
- 当前状态：**可交互原型**（单轨链条拼接 + 音乐检验），本仓库根目录为 Unity 工程
- 目标平台：PC（后续可考虑移动端）

### 1.3 核心幻想

> **波形 = 人格。** 每个人都有一个独一无二的「性格波形」；把不同的人接在一起，波形会拼成一段音乐。**拼出的音乐，就是「人与人的连接」本身。**

这一设定把「角色养成」「阵容搭配」「音乐节奏」三件事焊成一个东西：你「**看**」到一个人的节奏与形状（波形），「**听**」到他的嗓音与心（音色与和声）。

## 2. 设计哲学

### 2.1 为什么不做「音游 + 运营」的拼凑

核心机制（拼波形 + 音乐检验）**不应该是每天重复的玩法**，否则就退化成一款音乐游戏。日常必须回归「波形代表性格」的本质；音乐检验是**被期待的峰值时刻**，不是填充内容。

### 2.2 主题内核

> **人通过独处变好，通过相处变近。**

- 「练习」= 向内成长（波形向理想/熟练收敛）
- 「磨合」= 向外关系（波形向对方趋同）
- 整个游戏的一切系统，都是这一句话的两个出口

某种意义上是「**反着来的死亡搁浅**」：死亡搁浅连接一个个地点、让世界重新连通；这里连接一个个**人**，让一段段性格拼成一首能成立、甚至能打动人的曲子。

### 2.3 判定从「节奏对不对」转向「波形像不像」

- ❌ 旧思路：检验 = 卡不卡在拍点上（on-beat 打分）→ 本质仍是音游
- ✅ 新思路：检验 = 拼出的整条波形，**契合任务要求的性质组合**（像不像/听上去如何）

120 BPM / 4/4 只是这段「契合度检验」的**演出形式**，不是目的本身。

### 2.4 战略三角：做自己 vs 迎合潮流 vs 维系关系

波形有三个可变方向（见第 5 节），对应音乐公司的灵魂三问：

| 方向 | 机制 | 隐喻 |
|------|------|------|
| 练习 | 向「真我/理想」变 | **做自己** |
| 磨合 | 向「对方」变 | **维系关系** |
| 追流行 | 向「市场/趋势」变 | **迎合潮流** |

## 3. 核心概念：波形即人格

### 3.1 角色 = 一段波形段

- 一个角色 **不是一整条音轨**，而是**一段波形段**（可插在任意轨、任意时间点）
- 这段波形代表**一种特定的声音**，玩家可以**试听**（播放预览）
- 例：「温和 + 博学」→ 一段和声极度严谨、科班古典的温暖小提琴独奏片段

### 3.2 双通道呈现

波形同时渲染到两种感知里，玩家的记忆也是双通道：

| 通道 | 承载内容 | 对应维度 |
|------|----------|----------|
| **可见** | 波形（时间 × 音高块） | 节奏 + 旋律走向 |
| **可闻** | 声音（音色 + 和声） | 风格 |

> 你「看」到一个角色的节奏与形状，「听」到它的嗓音与心。

### 3.3 数据模型（当前原型）

- 一个角色由若干 `Tile` 组成：`Pitch`（音高，int）、`Duration`（时值，拍）、`Trait`（特质）
- 时值为浮点（0.5 / 1 / 1.5 / 2 拍）；120 BPM = 0.5s / 拍
- 拼接后由 `ChainTimeline.Flatten` 展开成时间线上的音符序列

## 4. 特质系统（三轴）

### 4.1 三根正交轴

角色 = 每根轴取一档，三条一交，程序化生成一段波形 + 声音。

| 轴 | 承载维度 | 示例（气质词 → 音乐效果） |
|----|----------|---------------------------|
| **风格轴** | 音色 + 和声 | 「刻板」→ 古典严肃乐；「激情」→ 摇滚；「跳脱」→ 电子乐 |
| **节奏轴** | 节奏型 | （待定档位） |
| **旋律轴** | 音阶走向 | 「不安」→ 日式小调 |

### 4.2 映射规则

- 每个特质 = **一组音乐维度的调制器**（在哪些维度上、往哪个方向偏）
- 音乐维度（约 5 个）：音色 / 和声 / 节奏 / 音高轮廓 / 动态（温度）
- 三轴 × 每轴若干档 ≈ 200+ 种角色组合

### 4.3 词汇原则（重要）

- 特质词必须是**内在气质词**（刻板 / 激情 / 跳脱 / 不安），**不描述出身或族群**
- ❌ 反例：「亚裔」这类族群词不能作为性格轴标签（会读成刻板印象，且破坏虚构一致性）
- ✅ 若需要地域/民族风味，放进**风格轴的「民族 / 世界音乐」档**（音色+律动），而非性格标签

### 4.4 记忆辅助

- 每个档位配**颜色 + 名词**，帮助玩家逐步形成「词 → 音乐」的条件反射

### 4.5 未明确项

- <span style="color:#d73a49">【未明确】</span> 轴数量：3 根（风格/节奏/旋律）为当前方案，是否加第 4 根「动态/强弱」轴待定
- <span style="color:#d73a49">【未明确】</span> 每根轴的具体档位词表（候选词尚未敲定）
- <span style="color:#d73a49">【未明确】</span> 每档映射到哪些具体音乐参数、组合时如何合成（「详细语法」，见 14 节）

## 5. 波形可变（三向）

### 5.1 三个方向

| 方向 | 机制 | 实现思路 |
|------|------|----------|
| **练习** | 向「真我/理想」变 | 磨平断点/抖动；高等级可**定点改波形**（在平的位置练出一个峰谷 = 音效多一个鼓点） |
| **磨合** | 向「对方」变 | 两个角色的波形**趋同**（带权 blend），解锁「合奏」 |
| **追流行** | 向「市场/趋势」变 | 安排角色做趋势相关事务会改变其波形（迎合变红） |

### 5.2 本真度（隐藏值）（注意，该内容大概率不做，是ai跑出来的一个多余设定）

- 越偏离原始波形，**本真度**越低
- 本真度高 → 后期能产出「**签名作品**」（别人学不来的独特风格，价值高但不一定大众）
- 追潮流 → 人气来得快，但稀释本真

> 这是游戏最核心的长期选择题：**做一个红的乐队，还是一个独特的乐队？**

### 5.3 万能角色弧线（通才 → 专才）

- 前期：角色库小，逼玩家养一个**万能角色**
- 后期：任务变「专」（如强黑暗风格 trap rap），万能角色「性质达标」但「风格不对味」，自然让位给专精角色
- **无需额外「退场」属性**——退场是任务设计**涌现**出来的结果

### 5.4 未明确项

- <span style="color:#d73a49">【未明确】</span> 磨合的「趋同权重 w」增长函数与上限（多次磨合 / 多对象 → 加权平均）
- <span style="color:#d73a49">【未明确】</span> 定点改波形的解锁等级与操作粒度（应限制在「改一格」，避免滑向自由作曲）

## 6. 任务与判定

### 6.1 任务形态（随进度放宽）

- **前期**：给出**前奏/桥**，或**缺了几个音轨的音乐** → 玩家用角色**接上/补齐**
- **后期**：条件放宽，鼓励玩家**自由创作**

### 6.2 音乐性质（任务要求的是「性质组合」，不是固定波形）

| 性质 | 含义 |
|------|------|
| **稳定度** | 节奏是否收在整拍、有没有打结 |
| **张力** | 音高落差、时值对比是否尖锐 |
| **温度** | 接口处两个角色的关系是融合还是摩擦 |
| **冲劲** | 单位时间密度、推进感 |

- 任务写成：「这一关需要一首**高张力、≥12 拍**的曲子，开头要一个沉得住气的角色」
- 同一个任务，几十种排法都算过关 → **没有唯一答案，不是拼图**

### 6.3 判定公式

> **任务判定 = 性质达标（能不能用）+ 风格对味（够不够好）**

- 「性质达标」：客观，达到要求的性质组合即可用
- 「风格对味」：主观，音色/风格是否贴任务的气质（通才永远「能用」、但难「对味」）

### 6.4 反随机（端口 / 障碍）

- 不是「拼图块」，而是**任务要求的硬锚点**
- **端口**：头/尾预设波形接口，需用合适角色接上才能启动
- **障碍**：音轨中途的硬约束，提升难度 / 暗示「这里该用什么波形」

### 6.5 未明确项

- <span style="color:#d73a49">【未明确】</span> 四个音乐性质（稳定度/张力/温度/冲劲）的具体计算方式
- <span style="color:#d73a49">【未明确】</span> 「风格对味」的量化（音色匹配的度量）

## 7. 评价系统（双通道）

### 7.1 两个独立维度

| 维度 | 性质 | 作用 |
|------|------|------|
| **契合度** | 客观 | 是否达到任务要求的性质组合（解决「能不能过」） |
| **角色评价** | 主观 | 角色对你作品的评价（驱动关系） |

### 7.2 角色评价 = 共振（关键设计）

> **角色评价不是一套独立的「气质标签」，而是「你的曲子与这个角色波形的共振度」。**

- 两者本来就是同一件事 → **「波形契合」与「高评价」等价**，挫败感从根上消失
- 于是「发现一个气质不搭的人、波形却契合」变成**高光时刻**：

> 玩家发现「嘴硬的老周」的波形竟与一首温暖前奏严丝合缝 → 老周给了高分 → 浮现一句：**「原来老周心里藏着一首这么暖的歌。」**

- 叠加「波形可变」：一个一开始不共鸣的人，反复磨合 → 波形靠近 → **越磨合越懂你**

### 7.3 与任务判定的关系

- 契合度决定**任务成败**；角色评价是**叠加的关系/情感层**，不卡主线
- 玩家聪明的「发现」永远在契合度上得到回报，不会被角色口味惩罚

## 8. 日常循环（回合制日历）

### 8.1 结构

- **回合制、点击过天数**：练习/磨合需要消耗天数，早晚触发事件
- 「等待」= 推进游戏内日历的**有意义的等待**，不消耗现实时间（不是挂机）

### 8.2 核心动作

| 动作 | 消耗 | 产出 |
|------|------|------|
| **练习** | 练习点 | 磨平断点/抖动、定点改波形 |
| **磨合** | 排练点 | 波形趋同、解锁合奏 |
| **接活** | — | 人气 + 知名度（高产出） |
| **研究趋势** | — | 新前奏 / 缺轨线索 |
| **招募** | 资源 | 新角色（新波形/特质） |

### 8.3 点数约束（混合制）

- 点数 = **时间恢复**（像体力，催人每天上线）
- 高级操作（定点改波形等）= 额外消耗**人气 / 材料**

### 8.4 人气经济

- 低等级角色 = 刚出道，人气低、不能自然增长
- **接活** = 攒人气 + 提高知名度 → 更高产出
- 人气激励角色**自己主动练习提升**（叙事合理性跑通）

### 8.5 早晚事件

| 类型 | 内容 | 作用 |
|------|------|------|
| **BGM 趋势片段** | 播放当前流行趋势风格的曲目片段（几句钢琴主旋律） | 传达趋势 + 练耳 |
| **小解密（听力测验）** | 听片段 → 猜风格/特质、或哪个角色能接得上 | 教「词 → 音乐」密码 + 给情报 |
| **角色对话/提案** | 小剧情，或建议玩家花精力做某事 | 填充故事 + 软引导 |

### 8.6 设计原则

- **每个日常决策必须至少做到三件事之一：喂沙盒 / 揭示角色 / 制造取舍**，否则是填充、砍掉
- **期限磁铁**：下一场大演出的倒计时，让每天的点数分配「有重量」

### 8.7 未明确项

- <span style="color:#d73a49">【未明确】</span> 练习点/排练点的具体数值与恢复速率
- <span style="color:#d73a49">【未明确】</span> 早晚事件的出现频率与密度（要够，但不要多到疲惫）

## 9. 作曲沙盒

### 9.1 定位

- 作曲**在日历外**：一个随时进入、不耗天数、没有计时器的自由空间
- 主题意义：**「在日常生活之外，找到一块创作的自我世界」** —— 日历里全是约束，唯独作曲是自由的

### 9.2 与日常的关系

- 沙盒是**峰值活动**，不是每天重复的填充
- 由任务/前奏触发；日常积累的角色、磨合、情报，最终都在沙盒里挥霍

## 10. 演出系统（两档）

### 10.1 两档结构

| 档位 | 形式 | 作用 |
|------|------|------|
| **大演唱会** | 定期、有预告 | 季节高潮 / 期限磁铁（deadline） |
| **小放送 / EP** | 玩家主动发起 | 资源水龙头（变现） |

### 10.2 留存 vs 变现（核心取舍）

- 任务完成后，完成的音乐可以：
  - **留在专辑里**（「我的作品」，长期积累）
  - **放送 / 出 EP 变现**（换资源，去练人/招募/投设备）
- 这是「**艺术 vs 商业**」张力落成的一个具体按钮

### 10.3 热度（建议方案，未确认）

- 建议**无损 + 热度衰减**：歌永远是你的（保专辑），但有「热度」随时间衰减
- 放送/EP 把「当前热度」换成资源；热度跌了收入就薄 → 持续判断「现在发还是等它更热」
- 追趋势的歌：热度起得猛、跌得也快；本真的歌：起来慢、掉得慢（快钱 vs 长线）

### 10.4 未明确项

- <span style="color:#d73a49">【未明确】</span> 放送/EP 是「消耗性」还是「无损 + 热度」（本文建议后者，用户未最终确认）
- <span style="color:#d73a49">【未明确】</span> 热度的数值曲线

## 12. 长期钩子：专辑

- 玩家的长期 build = **「专辑 / 作品库」**：每一首谱出的曲子都能随时回放
- 练习修顺的每一点、磨合连上的每一对，最终汇进这张专辑，变成「**这是我做的音乐**」

## 13. 现有实现（原型状态）

> 注意：当前原型是**单轨链条**（时间上的接力）；设计目标已升级为**多轨和声**（时间 × 音轨网格）。两者是不同阶段的形态。

### 13.1 技术栈

- Unity 2021.3.45f2c1，2D 模板，Built-in Render Pipeline，Unity China/UOS
- ⚠️ 勿改动 `Assets/UOSLauncherEncrypt` 与 `cn.unity.uos.launcher` 包

### 13.2 代码结构

```
Assets/Scripts/
├── Core/                  # 纯逻辑（无 Unity 依赖）
│   ├── Tile.cs            # 音符块：Pitch / Duration / Trait
│   ├── Character.cs       # 角色：Name / Tiles
│   ├── Trait.cs           # 特质枚举
│   ├── ChainTimeline.cs   # 链条 → 时间线展开（Flatten / TotalBeats）
```

## 15. 术语表

| 术语 | 含义 |
|------|------|
| 波形（Waveform） | 角色性格的可视化，由音符块（Tile）组成 |
| 波形段 | 一个角色对应的一段波形（可插在任意轨/时间点） |
| 音轨（Track） | 多轨和声中一条并行的声部 |
| 特质（Trait） | 角色的性格标签，映射到音乐维度 |
| 三轴 | 风格 / 节奏 / 旋律 |
| 练习 | 波形向理想/真我收敛（独处变好） |
| 磨合 | 波形向对方趋同（相处变近） |
| 追流行 | 波形向市场/趋势收敛（迎合变红） |
| 本真度 | 偏离原始波形的程度（隐藏值） |
| 契合度 | 客观：是否达到任务性质组合 |
| 共振 | 主观：曲子与角色波形的契合度 = 角色评价 |
| 前奏 / 缺轨 | 任务给出的残缺音乐，需玩家接上/补齐 |
| 端口 / 障碍 | 任务的硬锚点约束 |
| 大演唱会 | 定期演出（期限磁铁） |
| 小放送 / EP | 主动演出/发行（资源变现） |
| 热度 | 歌曲的时效价值（建议方案，未确认） |
| 专辑 | 玩家的长期作品库 |
